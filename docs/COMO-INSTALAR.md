## Cómo instalar Taller Mecánico

### 📱 Android
1. Descarga **Taller-Mecanico.apk** (abajo, en "Assets").
2. Ábrelo en el celular. Si Android lo pide, permite **"Instalar apps de origen desconocido"** para tu navegador o administrador de archivos.
3. Toca **Instalar**. Las versiones nuevas se instalan encima sin perder tus proyectos.

### 💻 Computadora (Windows)
- **Taller-Mecanico-Instalador-x.x.x.exe**: la instala con acceso directo en el escritorio.
- **Taller-Mecanico-Portable-x.x.x.exe**: se abre sin instalar (sirve en una USB).
- Si Windows muestra "Windows protegió su PC", toca **Más información → Ejecutar de todas formas** (la app no está firmada con un certificado de pago).

### 🧠 Activar el Maestro IA (opcional)
1. Crea una llave de API en console.anthropic.com.
2. En la app: **Ajustes → Llave de API → Probar llave → Guardar ajustes**.
3. Sin llave o sin internet, la app usa el **motor local**, que funciona siempre.

### 💾 Importante
Tus proyectos se guardan **sólo en ese equipo**. Usa **Ajustes → Exportar respaldo** seguido y guarda el archivo en otro lado.
